# Instant Delivery Analytics Project

## Overview
A simulated business analytics project built to mirror the responsibilities
of an Instant Delivery Strategy role. The workbook analyses 200 orders
across 6 months, covering buyer adoption, GMV performance, on-time delivery
rates, and a 6-month forecast model.

## Sheets
- RAW_DATA — 200 rows of simulated order transactions
- KPI_DASHBOARD — Live KPI metrics with targets and regional breakdown
- FORECASTING — 6-month projection model with editable assumptions
- PIVOT_ANALYSIS — Cross-tabulation by region, category, and driver
- CHARTS — Visual dashboard with 4 charts

## Tools Used
- Microsoft Excel (COUNTIFS, SUMIFS, AVERAGEIFS, dynamic formulas)
- MySQL (SQL project — see instant_delivery.sql)

## Business Questions Answered
- Which region has the highest GMV and completion rate?
- Are we hitting our monthly order growth targets?
- Which drivers are underperforming on SLA compliance?
- What is the 6-month revenue forecast under different growth assumptions?
